# INI 查找替换与回溯

## 使用

在“我的模组”顶部打开“INI 查找替换”。输入查找文本和替换文本，勾选要修改的模组，先查看命中的文件与次数，再执行“备份并替换”。默认全选，也可仅选几个。只扫描所选模组目录中的 `.ini`，包括子目录与未启用模组。

查找按输入原样、区分大小写的字面文本匹配，不使用正则表达式，也不再对 Hash 做特殊识别。查找文本不能为空；替换文本可以为空，以删除匹配片段。Unicode 文本需要 INI 采用 UTF-8 或 UTF-16 编码；不支持写入的编码会拒绝替换，避免乱码。

替换保留文件其余字节、BOM 与换行。每个匹配模组保存完整原目录备份，并生成新目录；批次记录与当前模组目录在同一次状态提交中保存。游戏加载目录通过现有部署事务同步，失败时维持原版本。

“替换记录”按时间倒序列出每批查找与替换文本、影响的模组与处数。“回溯记录”列出仍可回溯的批次，逐条“回溯到替换前”，按批次恢复备份，不做反向文本替换；已经回溯过的批次连同回溯时间单独列出。连续影响同一模组的批次须按最新批次优先回溯。回溯保留当前启用状态、模组身份和搭配方案。

## 文件变化与限制

预览后文件发生变化会要求重新预览。回溯前核对完整模组目录和备份的内容校验值；后续更新、移除、文件编辑或备份缺失时停止，避免覆盖新内容。备份目录保留在 `data/games/<游戏 ID>/library`，请保持整个 data 目录完整。每次替换需要受影响模组的完整副本空间。

跳过式部分替换没有启用：无法读取目录、存在链接、INI 过大或超过扫描限制时整批不执行。单个 INI 上限 16 MiB，全部 INI 总计 128 MiB；每个模组最多 25000 个文件/目录、40 层目录。预览凭证保存在主进程，15 分钟有效，不能从界面指定任意文件路径。

## 验证

自动测试覆盖字面匹配、大小写、所选模组范围、UTF-16 与换行保留，活跃/未活跃模组替换，重启后记录与连续回溯，过期预览、后续文件编辑保护，以及部署/状态落盘失败恢复。桌面测试完成输入、预览、确认替换、打开记录和确认回溯。
