# 批量 Hash 替换与回溯

## 使用

在“我的模组”顶部的“替换 Hash”打开二级窗口，分“查找替换 / 替换记录 / 回溯记录”三块。查找替换里输入查找值和替换值，先查看匹配文件与次数，再执行“备份并替换”。扫描所有已安装模组目录中的 `.ini`，包含子目录、未启用模组和 DISABLED 路径。完整值不区分大小写匹配，注释中的完整值也包含在预览中；不匹配更长标识符的一部分。接受 8–64 位十六进制数和可选 0x 前缀。

替换保留文件其余字节、BOM、换行和已有 0x 前缀。每个匹配模组保存完整原目录备份，并生成新目录；批次记录与当前模组目录在同一次状态提交中保存。游戏加载目录通过现有部署事务同步，失败时维持原版本。

“替换记录”按时间倒序列出每批“把哪个 hash 换成了哪个 hash”、影响的模组与处数。“回溯记录”列出仍可回溯的批次，逐条“回溯到替换前”，按批次恢复备份，不进行新值到旧值的反向文本替换，因此原本存在的新 hash 不会被误回溯；已经回溯过的批次连同回溯时间单独列出。连续影响同一模组的批次须按最新批次优先回溯。回溯保留当前启用状态、模组身份和搭配方案。

## 文件变化与限制

预览后文件发生变化会要求重新预览。回溯前核对完整模组目录和备份的内容校验值；后续更新、移除、文件编辑或备份缺失时停止，避免覆盖新内容。备份目录保留在 data/library，请保持整个 data 目录完整。每次替换需要受影响模组的完整副本空间。

跳过式部分替换没有启用：无法读取目录、存在链接、INI 过大或超过扫描限制时整批不执行。单个 INI 上限 16 MiB，全部 INI 总计 128 MiB；每个模组最多 25000 个文件/目录、40 层目录。预览凭证保存在主进程，15 分钟有效，不能从界面指定任意文件路径。

## 验证

自动测试覆盖精确匹配、大小写、前缀、UTF-16 与换行保留，活跃/未活跃模组统一替换，重启后记录与连续回溯，过期预览、后续文件编辑保护，以及部署/状态落盘失败恢复。桌面测试完成输入、预览、确认替换、打开记录和确认回溯。
