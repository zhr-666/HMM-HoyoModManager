# HoYoMod 0.9.9 Implementation Plan

> 用户已明确要求完成后发布 0.9.9 到 GitHub。界面冒烟测试依赖的 Playwright 未安装，未运行项按实记录。

**Goal:** 修复 0.9.8 反馈的 4 个问题，补齐回归测试，构建并发布 0.9.9。
**Architecture:** 更新状态由 `AppUpdate.init()` 在启动时按目标版本与实际版本核对，过期的未完成记录自动收尾；安装结构检查改为按文件夹名递归查找；模组右键菜单通过新增的 IPC 动作打开该模组自己的两个目录。
**Tech Stack:** Electron、Node 文件系统、原生渲染层。

## Task 1：残留更新状态自动清除

`src/core/app-update.cjs`、`tests/app-update.test.cjs`。

- `init()` 在 `recovery` 判定前读取 `plan.json` 的目标版本。
- 目标版本不高于当前版本时写入 `status.txt` 为 `complete`、删除 `current.json` 与本程序生成的 `HoYoMod-Recover.cmd`，保留任务目录，状态回到 `idle`。
- 测试：`updating` 记录 + 目标版本等于当前版本 → 清理且不再拦截；目标版本高于当前版本 → 仍为 `recovery`；`plan.json` 缺失 → 仍为 `recovery`。

## Task 2：设置键移回侧栏底部

`src/ui/style.css`。

- 删除 `.sidebar .settings-nav{margin-top:0}`，恢复 `.settings-nav{margin-top:auto}` 的底部定位。

## Task 3：递归检测 ShaderFixes

`src/core/library.cjs`、`tests/library.test.cjs`。

- 删除 `GIMI_ROOT_FOLDERS` 与 `gimiLayoutFolders()`，新增递归查找 `ShaderFixes`（大小写不敏感）。
- 报错文案说明该文件夹需要放在 GIMI 根目录，请手动安装。
- 测试：顶层 `ShaderFixes`、模组文件夹内 `ShaderFixes`、多级子目录 `ShaderFixes` 均被拒；顶层 `BufferValues`、`mods` 加附带文件夹改为可安装；本地导入路径同样拒绝。

## Task 4：模组右键打开自身目录

`src/main.cjs`、`src/ui/app.js`、`src/ui/style.css`。

- 新增 IPC 动作：按模组 ID 打开本机库副本目录，或打开 `GIMI/Mods/HoYoModManaged/<id>`；路径由主进程计算并校验父目录。
- 未启用时部署目录不存在，右键菜单中该项变灰并说明原因。
- 界面断言加入现有冒烟脚本；无 Playwright 环境时记录未运行。

## Task 5：验证与产物

- `node scripts/check-syntax.cjs`、`node --test tests/*.test.cjs`。
- 版本升到 0.9.9，README 增加本版说明并同步下载文件名。
- 构建 Windows x64 ZIP，校验包内容与 ZIP 更新准备流程。
- 提交、推送 `main`、打标签 `v0.9.9`、创建 Release 并上传 ZIP 与 SHA256。
- 在 `docs/releases/0.9.9.md` 记录实际命令、结果与未验证项（含 Windows 实机与界面冒烟）。
