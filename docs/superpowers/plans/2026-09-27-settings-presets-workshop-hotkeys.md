# 设置、方案与工坊热键实现计划

**目标：** 完成设置页视觉优化、主页方案快捷切换、工坊窄栏点击展开及热键来源关联。

**依据：** `docs/superpowers/specs/2026-09-27-settings-presets-workshop-hotkeys.md`

1. 为工坊来源热键补回归测试：未安装时暂存、安装后自动并入、失败后可重试、已安装直接保存、本地 ID 行为不退化。先确认测试复现当前错误，再修改 `src/core/library.cjs`、`src/main.cjs` 与 `src/ui/app.js`。
2. 更新设置页和主页的界面结构与样式，删除维护区多余入口。主页方案按钮使用现有 `applyPreset`；补正常、空方案和失败反馈的界面测试。
3. 收起工坊菜单时扩大点击区域，并避免 Windows 标题栏遮住其顶部。补菜单展开与窗口拖动区域测试。
4. 运行受影响的 Node 测试、界面资源缓存测试、`pnpm check` 和 Electron 冒烟脚本；审查并提交本任务文件。Windows 上后续确认设置页、滚动与实际鼠标操作。
