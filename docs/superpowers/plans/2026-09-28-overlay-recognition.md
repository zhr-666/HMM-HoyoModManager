# beta2 角色识别与悬浮窗实施计划

**目标：** 提升千织、甘雨、奥黛塔等角色识别的速度与稳定性，修复拖动回弹，实现圆形入口与展开收回动画。
**方案：** 在现有捕获、监测、窗口控制及 UI 模块内修改，保留两个原生窗口，用展开窗口的形状动画衔接入口。
**技术：** Electron / Tesseract.js / Node 测试，无新增依赖。
**规格：** [设计说明](../specs/2026-09-28-overlay-recognition.md)

用户授权明确，按仓库协作规则直接执行，不重复申请流程批准。由当前会话实施，最终独立审查只做一次。

## 重点审查

- 切到另一个已知但没有已启用热键的角色，不得继续显示旧角色热键。
- 拖动时识别状态变化、松手发生在窗口外、保存失败均不应回弹。
- 动画期间退出游戏或快速开关，过期完成消息不得使窗口重新出现。
- 模糊候选冲突拒绝确认；两个字不靠近似字猜测。
- 设置调整和屏幕边缘展开，入口返回保存位置，动画坐标不越界。
