# 三游戏工作区 Implementation Plan

**Goal:** 三游戏工作区与独立配置，共用全部模组规则。
**Spec:** ../specs/2026-09-22-multi-game.md
**Architecture:** 游戏注册表 + 同类服务多实例 + 异步操作绑定来源工作区；原神旧数据原址保留。

- [x] 核实公开 API 并集中游戏配置，参数化分类/详情/加载器，增加各游戏测试。
- [x] Library 支持固定游戏、独立元数据根/安装库根、共享预览根和全局偏好；实现 WorkspaceStore、路径保护、当前游戏持久化，覆盖隔离/旧数据/并发测试。
- [x] 主进程请求和队列绑定工作区；分离任务状态与缓存；全局通知标注来源，更新器保护所有游戏。
- [x] 界面动态渲染三个游戏，切换库/工坊/设置，隔离异步结果，参数化图片与加载器文案。
- [x] Electron 多游戏测试、全量与专项回归、差异审查、data 文档。

## 约束
保留所有已有修改；不自动提交、打包、发布。游戏资源允许新增但需 UI_ASSETS 白名单；Windows 验收单列。新游戏安装库均在 data/library 下。旧原神 data 文件不移动。
