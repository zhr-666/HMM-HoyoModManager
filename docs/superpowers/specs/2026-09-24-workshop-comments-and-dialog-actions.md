# 工坊评论与窗口操作整理

## 目标

- 二级及更深弹窗仅在标题栏保留左上「返回」和右上关闭按钮；底部只显示需要确认的操作，不重复显示取消、关闭或返回。
- GameBanana 模组详情中，在文件列表上方提供默认折叠的「查看评论」，展开后按页读取并显示评论；网络失败时可重试。
- 有回复的评论可继续展开，按需读取该条评论的回复及后续页；失败后可重试。
- 每个文件右侧提供「下载此处」，交由系统浏览器打开 GameBanana 对应文件下载地址；原有「下载并安装」仍将模组安装到本机安装库。

## 边界与验收

- 用户明确表示若无法完成程序内登录和直接发表评论，就不做登录功能。核查 [FlairX Mod Manager 源码](https://github.com/Jank8/FlairX-Mod-Manager/tree/7ddae4f62d15265170f889c889071256972c36d6) 后，确认其内嵌登录仅用于获取网页会话以读取评论，并未实现发表评论；GameBanana 可验证接口支持读取模组评论和评论回复。因此本次借鉴回复浏览交互，不增加登录、凭据保存或发评论控件，也不复制其 GPL 源码。
- 评论内容按纯文本转义显示，不执行 GameBanana 返回的 HTML 或模组内代码。
- 文件编号由主进程验证；只有 `https://gamebanana.com/dl/<文件编号>` 可通过新入口打开。
- 弹窗的关闭、返回、Esc 与前置模组提醒的取消语义保持有效；进行中任务的「取消」、撤销忽略等业务操作不受影响。
- 界面资源缓存规则、data 和 GIMI 文件保持现状；本次不修改版本号或制作发布产物。Windows 更新后的界面仍需实机验收。
