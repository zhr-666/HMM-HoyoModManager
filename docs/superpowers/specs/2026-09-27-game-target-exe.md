# 各游戏目标 EXE 设置

## 目标

每个游戏可在“当前游戏设置”中选择自己的目标游戏 EXE。该路径仅用于识别正在运行的游戏进程，不用于启动程序，也不改变模组安装或启用。

## 行为

- 设置页和首页的当前游戏设置窗口都显示并允许选择目标游戏 EXE。选择文件取消时保留原值；无效文件不保存。
- 路径保存在该游戏的 `state.json`，切换游戏或重启后各自保持。未设置时不捕获画面。
- 现有原神热键监控只在当前游戏为原神时运行，并以所选 EXE 的完整路径匹配前台进程。匹配失败时隐藏热键悬浮窗。
- 此次不增加其他游戏的 OCR 规则、角色名区域或热键悬浮窗。

## 验收

自动测试覆盖各游戏设置隔离和重启恢复、所选进程匹配与未设置时停止捕获、界面资源缓存规则。Windows 实机需验证选择原神 EXE 后的实际画面识别和悬浮窗行为。
