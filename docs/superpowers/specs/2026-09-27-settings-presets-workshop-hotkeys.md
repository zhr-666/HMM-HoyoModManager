# 设置、主页方案与工坊热键交互

## 范围与验收

- 只优化「设置」页的「当前游戏设置」卡片。三个配置项和原有按钮语义保持不变，采用与深色启动器一致的分组、间距、状态展示；主页齿轮弹窗不改。
- 「维护与诊断」移除「检查更新」按钮；「我的模组」中的模组更新入口与「软件更新」入口保留。
- 主页「当前搭配方案」不再列出启用数量或启用模组。显示当前方案名称与已保存方案的名称按钮；点击名称立即应用，应用失败时保留原状态并显示现有错误提示。没有保存方案时显示引导文案，仍可进入方案管理。
- 工坊菜单收起时，点击窄栏任意位置都展开。顶端窄栏也可点击；因此收起状态下该宽度的标题栏不占用点击区域，剩余标题栏仍可拖动窗口。展开状态的顶部拖动行为保持。
- 工坊详情右键「设置为热键提示」使用 GameBanana 来源编号。若已有对应安装库模组，直接保存到该模组；若尚未安装，按来源编号暂存，并在该来源模组安装成功时并入模组热键提示。暂存项按游戏工作区隔离；失败或取消安装不清除暂存项，重复文字不生成重复提示。已有按本地 Mod ID 保存、查看和删除热键提示的行为保持。

## 实现边界

界面改动位于 `src/ui/index.html`、`src/ui/style.css`、`src/ui/app.js`。热键入口经 `src/main.cjs` 传入来源编号；`src/core/library.cjs` 在现有 `hotkeyNotes` 状态里使用 `source:<来源编号>` 暂存，并在安装事务提交时转移到本地 Mod ID。无需新增依赖、版本号或数据迁移脚本。

## 验证

先复现来源编号被当作本地 ID 的错误；新增未安装、已安装、失败后重试及重启持久化测试。运行相关 Node 测试、`tests/ui-assets.test.cjs`、`pnpm check` 与受影响的 Electron 界面冒烟测试。macOS 结果不代替 Windows 实机界面验收。
