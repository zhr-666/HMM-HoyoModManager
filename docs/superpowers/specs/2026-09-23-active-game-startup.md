# 启动时只读取当前游戏状态

用户要求：首页启动时只读取当前游戏的 `state.json`；切换游戏后再读取目标游戏。当前的 `Workspaces.init()` 会按顺序初始化三款游戏，导致无关游戏的状态与缺失热键扫描也阻塞首页。

方案：先读取 `workspaces.json` 确定当前游戏，再仅初始化它的 `Library`。为未加载游戏保留工作区对象，首次选择或对该游戏执行操作时初始化其状态与下载队列。初始化和选择失败时保持原游戏；同一游戏的并发请求共用初始化过程。启动后的背景任务只运行已经初始化的游戏。路径冲突校验在修改启用目录时按需读取其他游戏状态；软件更新准备时按需收集所有游戏的受保护路径，不能因未加载而漏保护。

验收：用不同游戏的状态文件验证启动只读取所选游戏、切换后读取目标游戏、坏的非当前状态不阻止首页而选择时明确报错；现有多游戏隔离、下载队列和 UI 切换行为保持可用。首页体积统计仍针对当前游戏，体积缓存不在本次范围。
