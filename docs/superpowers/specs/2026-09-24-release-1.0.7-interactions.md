# v1.0.7 交互修改与发布

## 目标

- 模组工坊详情页点击当前大图，在程序内另开一层放大浮层查看原图；返回后保留详情页原有状态和图片选择。
- 右下角完成／错误通知由用户点击自身叉号关闭时，删除该条通知中心记录并更新未读数；8 秒自动收起仍保留历史。关闭通知中心面板不删除记录。
- 工坊排序显示 GameBanana `Mod/ListFilterConfig` 当前列出的全部 12 种模组排序，选择后按对应 `_sSort` 请求，保留筛选与分页逻辑。
- 合入此前完成的工坊评论、窗口操作、鸣潮背景和设置提示改动，打包并发布 `v1.0.7` 到 `zhr-666/HMM-HoyoModManager`，Release 正文精确使用用户提供的“优化部分交互逻辑和页面UI，修复鸣潮背景问题”。

## 设计与边界

- 用户已明确选择程序内浮层。图片复用现有可信地址校验与对话框栈，显示在详情页上方，返回／关闭只收起放大层。
- 界面资源保持 `cache-control: no-store` 与启动清缓存规则。
- 排序别名以 [GameBanana 模组排序配置](https://gamebanana.com/apiv11/Mod/ListFilterConfig) 为准。无效排序键回退到“最新发布”。
- 不改变安装／启用语义，不清理用户 `data`、GIMI 等加载器目录，不执行模组文件，不添加登录或发表评论。
- 版本号由用户明确指定为 `1.0.7`。发布前运行项目基础检查、受影响界面冒烟测试、Windows x64 包内容和更新准备检查；macOS 构建不能替代 Windows 实机升级验收，发布记录如实注明未验证项。
