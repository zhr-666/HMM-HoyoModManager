# 下载、筛选与更新修改

本次修改现有 Windows 便携版，保留同角色互斥与旧版本失败回滚。

- 工坊支持下载量、上传时间、更新时间排序；SFW 和 NSFW 可分别勾选，默认都勾选。按来源站内容评级分类，不分析图片内容。
- NSFW 预览默认模糊，点击预览显示；设置可关闭默认模糊。包含工坊、详情及本地库预览。
- 下载保存页面网址、页面上传时间、文件 ID、文件名与文件上传时间；下载记录在安装失败时保留完整包、错误和重试入口。
- 使用 Electron 网络栈沿用系统代理；流式写盘、速度显示、可验证的重试。不能保证突破来源站或网络本身的限速。
- 更新依据文件上传时间，不依据页面编辑时间。比较已安装文件的上传时间与来源页最新文件时间；最新时间存在多个文件则全部展示。
- 检查结束后统一列出有更新条目、失败条目和无法判断的旧记录。每个 Mod 标记状态，更新始终由用户手动选择文件执行。旧自动更新开关迁移为自动检查更新。
- 老记录若有唯一匹配文件可补全时间；无法确认则标记未知，不猜测已安装版本。
- 安装失败的用户报错仍在等待反馈。独立核实代码可复现的问题并补充阶段化错误日志，不把未经复现的问题标记为已修复。

验证：API 模拟与真实元数据检查；文件时间比较与同时间并列测试；下载中断/缓存/重试测试；真实 Electron 界面测试；Windows x64 ZIP 完整性及打包依赖检查。
