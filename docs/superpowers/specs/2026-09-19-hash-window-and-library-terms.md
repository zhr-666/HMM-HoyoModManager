# 替换 Hash 二级窗口、导入存放位置与安装/启用术语

## 背景

1.1.0 之后用户提出四点改造：

1. 批量替换 Hash 从「我的模组」工具条里的一对按钮升格为一个大功能，入口放在顶部按钮行，点进去是一个二级窗口，窗口内有「查找替换 / 替换记录 / 回溯记录」三块。
2. 去掉「全部停用」按钮。
3. 「新建文件夹」入口去掉，改为：点「导入本地模组」→ 选压缩包 → 按 GameBanana 分类选择存放位置；选位置时**大分类也可以直接存放**，不要求一定进到最小子分类。导入按钮上要有问号指引（悬浮提示「选择文件后选择安装位置」）。
4. 顶部两个按钮改名：「打开本机库」→「安装库」，「打开 Mods 文件夹」→「启用库」；并把「安装 / 启用」的定义写进项目规则。

## 术语（写进规则）

- **安装**：把下载（或本地选择的）压缩包解压后的模组副本放进程序目录下的 `data\library`，即「安装库」。安装只决定模组在本机库里的归属分类文件夹，不写 GIMI。
- **启用**：把安装库里的模组副本放进 GIMI 文件夹（受管理的是 `GIMI\Mods\HoYoModManaged\<模组 ID>` 或用户选择的 Mods 子目录），即「启用库」。启用是游戏内真正生效的一步，只操作程序自己拥有的部署目录。

## 决定

### 1. 替换 Hash 入口与窗口

- 入口：顶栏 `.top-actions` 一行，与「安装库」「启用库」并列，文案「替换 Hash」，只在「我的模组」页面显示（与另两个按钮的可见范围一致）。
- 形式：复用现有 `#modal` 对话框（二级窗口），内部用标签切换三块内容。
  - **查找替换**：查找值 / 替换值输入 + 「查找并预览」，预览结果直接渲染在窗口内（不再关窗再开窗），命中时给出「备份并替换」。
  - **替换记录**：只读日志，按时间倒序显示每次替换把哪个 hash 换成了哪个 hash、影响哪些模组、多少处、当前状态（已替换 / 已回溯）。
  - **回溯记录**：列出仍可回溯的批次，逐条提供「回溯到替换前」（窗口内联确认），并单独列出已经回溯过的历史。回溯语义不变：按批次恢复替换前的完整目录，不反向替换文本；模组后续更新、移除或被手动改动时停止。
- 数据不变：沿用 `hashBatches`（`oldHash/newHash/createdAt/count/status/entries`），无迁移；回溯历史直接由 `status==='rolledBack'` + `rolledBackAt` 派生。

### 2. 去掉「全部停用」

- 移除「我的模组」工具条与「设置 → 维护与诊断」两处按钮及其界面绑定。
- 保留核心 `disableAll()` 与 `disableAll` IPC 动作（自动化与故障排查仍可用），不做无谓的连锁删除。

### 3. 新建文件夹并入导入流程

- 移除独立「新建文件夹」按钮与 `chooseLibraryFolder({mode:'create'})` 分支；导入存放位置弹窗只有一个用途：为选中的压缩包选存放分类。
- 选择规则放宽：任意层级都可以确认存放（原来要求 `path.length>=2`，即必须进到角色/子分类）。
- 大分类（总分类）作为存放位置时，磁盘上是**一级**目录 `data\library\<总分类>-<哈希>`，模组直接放在里面；子分类/角色仍是两级 `总分类/角色`。
- `resolveCategory` 不再拒绝一级路径；`library.createFolder`/`install` 共用同一条层级推导（选中节点就是总分类时只建一级）。
- 互斥语义不变：`characterGroups` 里总分类与角色层的分组值为 `null`，同组为空表示不互斥，因此大分类里的多个模组可以同时启用；角色分类仍互斥。

### 4. 按钮改名与问号指引

- `#open-library-button` 文案「安装库」（仍打开 `data\library`），`#open-mods-button` 文案「启用库」（仍打开 GIMI 的 Mods 目录）。
- 「导入本地模组」按钮带 `data-tip-text="选择文件后选择安装位置"` 与行内问号标记，鼠标悬浮（或键盘聚焦）时用现有 `#help-tooltip` 弹出提示。

## 验收

- 顶栏「替换 Hash」只在「我的模组」显示，点开是三标签窗口，可完成 查找预览 → 备份并替换 → 在替换记录里看到该批次 → 在回溯记录里回溯到替换前。
- 「我的模组」与设置里都不再有「全部停用」；不再有「新建文件夹」。
- 导入选位置时可以停在「Skins」这样的大分类直接确认，磁盘上只出现一级目录；模组能正常启用/停用。
- 单测与冒烟脚本更新，`pnpm check` 通过。

## 未覆盖
