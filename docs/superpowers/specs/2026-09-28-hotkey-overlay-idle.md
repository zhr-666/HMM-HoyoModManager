# 热键悬浮窗待识别状态

## 目标

原神在前台且画面捕获可用时，即使尚未识别到有热键的角色，也保留一个可见的悬浮入口，让用户知道画面识别正在运行。待识别入口显示半透明的 HMM 程序 Logo。

## 状态与行为

- 游戏未运行、不在前台、未选择原神工作区或当前显示器不支持捕获时，隐藏入口和详情窗。
- 游戏在前台并取得有效画面后，未识别到有热键的角色时显示半透明程序 Logo；此状态仍可拖动并保存入口位置，点击不展开空白详情窗。
- 连续识别到有热键的角色后，在同一入口位置显示原有角色热键按钮；识别失配后按现有两帧稳定规则退回 Logo，并关闭已展开的详情窗。
- 捕获或 OCR 报错时保持现有报错与隐藏行为，不用 Logo 冒充正常工作状态。重试成功后恢复待识别或已匹配状态。
- 复用 `src/ui/app-icon.png`，不新增图片资源、依赖或设置。仅在图像可见时降低透明度，入口窗口背景保持透明。

## 验收

自动测试覆盖前台待识别、匹配、失配回退、后台隐藏、错误恢复与空白详情窗不可打开；Electron 冒烟测试确认 Logo 成功加载、可见且状态切换正常。界面改动运行 `tests/ui-assets.test.cjs` 和 `pnpm check`；Windows 游戏内点击和覆盖仍需实机验收。
