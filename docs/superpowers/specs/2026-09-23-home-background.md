# 游戏主页 Logo 与背景稳定切换

用户要求：原神主页与绝区零/星铁一样显示左上角文字 Logo；修复游戏切换时背景卡顿、瞬间串图。

原因：原神 Logo 被主动隐藏；单一 img/video 直接换 src，视频切走即卸载，切回重新加载解码；Logo 在每次状态渲染时重复赋 src。初始 HTML 还固定加载原神背景，恢复其他游戏时可能先闪原神。

方案：三游戏配置显式 logo，新增官方原神文字资源及版权说明/白名单。独立 Logo 对三款游戏始终可见；原神内置背景选用官方无文字版本。独立背景控制器按游戏和资源版本持有当前一组已解码图片、Logo、视频，未选中视频暂停。先完成准备，再原子替换显示节点；旧加载结果不提交。游戏切换先准备下一场景，再提交游戏状态。同一资源的重复状态刷新不加载；损坏自定义图片回退本游戏默认背景，视频失败回退本游戏静态图。缓存只存在当前渲染进程，不改变 no-store/启动清磁盘缓存约束。

用户后续要求把三款游戏当前最新的官方背景直接作为内置默认图，不保留旧图，并控制程序体积。2026-09-23 查询 HoYoPlay 接口：绝区零、星铁的现有 WebP 已是接口首图；原神需要替换旧版官网图。三款均只打包一份 1920×1080 压缩 JPEG 静态图；保留按需下载的官方视频与用户自定义背景功能，且不删除用户 `data` 中已保存的媒体。

用户再次确认原神 Logo 必须始终可见，并明确要求以最新无文字的官方背景替换当前内置图。独立 Logo 不再按背景来源隐藏；内置原神默认图片取自 `getGames` 接口的 `display.background` 原始画面，避免与独立 Logo 重叠。运行时“获取官方背景”仍使用原有 `getAllGameBasicInfo` URL，不修改请求逻辑。

验证：真实 Electron 复现重复 Logo 赋值；单测覆盖异步过期、同资源复用、错误回退及视频暂停恢复；三游戏冒烟验证 Logo、资源缓存头、快速切换与视频复用。pnpm check、ui-assets 与专项冒烟。Windows 更新后视觉表现仍需实机验收；不升版、不打包发布。
