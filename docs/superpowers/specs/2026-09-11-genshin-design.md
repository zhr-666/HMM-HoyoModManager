# 原神 Mod 管理器设计

## 已确认需求
Windows x64 便携版，解压运行。简洁中文工具界面。第一版原神，游戏适配层保留扩展。
按角色浏览 GameBanana 的 Mod，展示作者预览图片，选择文件下载并安装；支持本地导入。
同一个角色最多启用一个 Mod，不同角色可以同时启用。搭配方案保存各角色启用项并完整切换。
从本程序启动 XXMI/GIMI 并启动原神；运行中切换后尝试 F10 刷新，不能确认游戏内结果时明确提示。
设置包含下载后自动启用、自动更新 Mod，两者默认关闭。手动检查更新与安装更新始终可用。

## 方案
采用 Electron 本地桌面程序。相比 .NET/WPF，可以在当前 macOS 工作环境验证界面并打包 Windows ZIP；相比自研注入器，接入上游 XXMI 降低游戏版本适配维护工作。
所有管理器持久数据放在可执行文件同级 data 目录。开发模式使用项目 data。游戏与 XXMI 可位于外部目录，复制便携版后可重新选择路径。
管理器负责下载官方 XXMI portable 发行包并解压，首次初始化通过 XXMI 自带设置安装 GIMI 与选择游戏。完成后主程序无界面调用 --nogui --xxmi GIMI。也支持选择既有 XXMI。
不声称自研或已经实测游戏注入成功。自动刷新使用 Windows API 聚焦匹配的游戏窗口并发送 F10，失败则引导手动按 F10。

## 数据与行为
本地 JSON 状态原子写入，含 settings、mods、presets。资源包存入 data/library 的独立 ID 目录；仅启用项复制到 GIMI/Mods/HoYoModManaged。该目录仅由管理器拥有，禁止覆盖非本程序目录。
切换时暂存新部署，旧部署移入不被 GIMI 递归加载的 DISABLED 前缀目录，写入状态成功后清除旧部署。失败恢复旧目录和状态。启动时恢复未完成事务。
角色互斥以 GameBanana 角色分类 ID 或本地用户选择的角色 ID 为键。未知角色需选择归属，禁止自动混入。
更新替换原条目资源并保留角色、启用状态与方案引用；文件版本有歧义时要求选择，自动更新只使用此前同名文件。
压缩包支持 zip/7z/rar。检查路径穿越、链接、可执行文件和大小限制，解压进临时目录，验证包含 ini 后提交。下载不运行作者脚本。
远程内容只作为文本与 HTTPS 图片展示。渲染器无 Node 权限，通过白名单 IPC 调用本地能力。

## 验证与交付
核心测试覆盖互斥、多角色、方案、事务恢复、失败回滚、压缩包拒绝规则、网络结构和更新决策。真实公开 API 冒烟测试；桌面 UI 检查；生成 Windows ZIP。
当前主机是 macOS，Windows 游戏启动、刷新与真实原神 Mod 兼容性必须在 Windows 实机验收；交付时明确此边界。
