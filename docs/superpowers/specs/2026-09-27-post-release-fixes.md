# v1.0.8 后续修复与模组工具设计

## 目标与边界

修复通知、弹窗导航、预览图粘贴问题，并扩展模组更新、ShaderFixes 清理、INI 文本替换和诊断日志。保持 Windows x64 便携程序、现有 `data` 与 GIMI 用户文件安全。不修改软件版本号，不制作或发布新版本产物。

## 通知与更新检查

- 通知中心按钮始终能响应；通知浮层不覆盖自身按钮或二级窗口的关闭按钮。二级窗口右上角关闭按钮始终可点，关闭窗口不取消已经开始的后台检查。
- “我的模组 → 检查更新”立即打开二级窗口，顶部提供“开始检查”和进度。窗口列出所有模组的已忽略版本，并能逐条取消忽略；检查完成后在同一窗口展示结果与可安装更新。通知中心同步显示进行中任务的进度，完成或失败仍有相应消息。自动检查也更新当前窗口进度和结果。
- 检查结果与忽略列表依据当前游戏更新，避免切换游戏后的旧结果进入当前窗口；重复点击不并发启动第二次检查。

## 弹窗与来源

- 所有左上角“返回”退一层。导入位置选择器有分类层级时退到父分类；在“全部分类”再返回则结束导入并回到“我的模组”。关闭按钮直接关闭当前二级窗口；忙碌状态下也可点击，后台任务独立完成。
- ShaderFixes 历史与 INI 替换分别打开独立二级窗口。工坊详情删除文件行右侧的“下载此处”按钮。我的模组的 GameBanana“来源”在当前界面打开现有工坊详情二级窗口；普通自定义来源网址仍按现有方式处理。

## ShaderFixes 清理

- 新安装记录保存每个实际写入文件的 SHA-256。历史里的“删除本次添加的所有文件”仅处理该批次 `written` 文件：内容与记录一致的存在文件可删除；后来修改的文件跳过；不存在的文件明确提示；已跳过的项目不触碰文件。
- 清理前重新验证路径边界与链接，避免删除非该批次拥有的文件。清理结果逐项落盘，失败或中断后可重试剩余项。允许删除纯 `skipped` 历史记录。
- v1.0.8 旧记录没有文件校验值，不显示在新版历史列表中，也不删除其实际文件；历史 JSON 保留以避免误删依据。新记录中全部已跳过的批次允许删除记录。

## INI 查找替换

- 原“替换 Hash”扩展为按原样、区分大小写的字面文本查找替换；不使用正则和旧 Hash 的特殊匹配规则。仅扫描用户勾选模组的 `.ini`，默认全选。允许空替换文本以删除匹配片段，查找文本不能为空。
- 继续沿用先预览、再备份替换、记录与回溯流程，保留失败时对用户库和启用目录的保护。预览和执行必须使用同一份模组选择和查找值；中途文件变化则拒绝执行。

## 预览图与日志

- 修复从系统剪贴板读取图片并添加预览图的实际报错，覆盖无图、有效图片、超限与保存路径。
- 在 `data/logs` 建立可分享的诊断日志，记录时间、来源、错误栈及必要任务上下文，包括主进程异常、IPC、后台任务、渲染进程错误和 Promise 拒绝。日志不记录模组文件正文、剪贴板图片或代理凭据。控制日志大小与保留份数，在设置中提供打开日志目录的入口；日志失败不能阻断程序操作。

## 验收

受影响行为新增回归测试，包含正常、失败、取消或恢复路径；运行 `pnpm check`、`tests/ui-assets.test.cjs` 及相关界面冒烟脚本。macOS 结果不替代 Windows 实机验收，发布前仍须在 Windows 检查更新后 UI 资源与实际文件操作。
