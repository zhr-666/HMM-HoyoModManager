# 工坊分页与搜索、会话通知和下载排序

本规格覆盖 2026-09-27 提出的四项调整，并取代旧通知规格中关于历史跨启动保留的规定。

## 行为

- 工坊每页最多 20 个模组；除最后一页外，筛选后也要有 20 个。仅看 NSFW 或 SFW 时跨 GameBanana 上游页收集，不能直接把一页过滤后当作一页。翻页不重复模组。
- 工坊输入框同时查模组名称和完整作者名，作者名经 GameBanana 成员接口解析为 ID；模组名与作者名搜索均不区分大小写。两类结果去重，作者结果先展示，其后展示同名模组；筛选、游戏与分类仍生效。作者接口不可用时继续查模组名。
- 通知消息只存在于本次程序运行的内存里。启动时删除旧版 `data/notifications.json`，当前运行不再写入。右下角提示、未读、手动删除、清空与任务卡仍按现有界面操作。下载队列和安装记录继续独立保存。
- 下载列表按任务创建时间从新到旧显示，时间相同维持原顺序。下载队列实际执行顺序不变，旧版安装记录也纳入显示排序。

## 验收

单元测试覆盖 NSFW 跨页、作者和标题搜索、重启后通知清空、旧文件清理，以及下载排序不修改原队列。运行 `pnpm check`、`tests/ui-assets.test.cjs` 和相关 Electron 冒烟脚本；发布前仍需 Windows 实机检查。
