# 角色互斥与按钮单行

## 已确认需求

仅同一角色的角色 Mod 互斥，不同角色及非角色类型允许同时启用多个；所有操作按钮文字不换行。

## 实现范围

- 使用 GameBanana Characters 分类 ID 18140 下面的具体角色作为互斥组，同一角色下更深的分类也归属该角色。
- 工坊详情携带 characterGroupId，下载记录与模组记录保留该字段，支持离线启用与搭配方案。
- 已安装模组读取 taxonomy.json 和旧 categories.json 缓存来判断角色；已知分类会随状态写入保留。早期没有根分类字段的角色库保留原有角色互斥行为。
- 非角色分类和本地导入不参与互斥。角色归属未知的旧 Skins 条目按需联网获取分类并保存；离线且缓存也不能判断时拒绝启用该条目或相关方案并提示刷新分类，不把未知角色静默当作非角色。已保存分类的模组继续支持离线操作。
- enable、前置检查的启用预览与 applyPreset 使用同一角色分组逻辑。互斥仅改变启用状态，不删除模组；冲突方案拒绝执行并保留原状态。相同分类可共享已有可靠分组；仍有未分类的已启用 Skins 时，不能通过启用另一已知角色来绕过判断。
- 按钮标签统一 nowrap，操作按钮不被压缩到换行；按钮组可整体折行。分类卡片长名称单行省略，名称与辅助信息各自保持原来的层次。
