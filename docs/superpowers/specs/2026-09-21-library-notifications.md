# 通知与本机模组资料管理

## 已确认需求
- 软件与模组启动自动检查：没有更新时无弹窗、无历史消息；有更新或检查失败时弹出通知并保留历史。手动检查仍有完成反馈。
- 通知中心常驻「进行中的任务」「消息」两个可折叠分区，空时也显示标题；完成任务移出进行中区。未读只显示红点，取消循环闪烁。
- 右键切换皮肤模组标记。同角色可启用任意多个皮肤模组，普通模组最多一个；安装库保存数量不受限制。搭配方案遵守相同规则。
- 右键管理预览图：二级窗口展示所有图片，右上角叉号删除，虚线加号添加，从文件或剪贴板选择。卡片多图通过悬浮/键盘聚焦时显示的左右箭头循环切换。
- 本地导入依次选择压缩包、分类、选填来源网址/作者/预览图，再安装。右键也可编辑这些资料。

## 实现决策与数据保护
- 旧记录未标记则视为普通模组；旧单张预览兼容展示。显式空图片数组代表用户删除全部，不能回退显示旧图。
- 将已启用皮肤改为普通时，以该模组为当前选择，停用同角色原普通模组；保存方案冲突时拒绝应用，保留当前部署。
- 用户资料独立于工坊更新识别编号；填写来源网址不自动绑定远程更新。用户编辑的作者、来源、预览与皮肤标记在更新后保留。
- 图片选择只读，取消不落盘；保存时复制至 data/previews，不修改原图片。先写图片，再原子写状态；失败清理本次新图片，旧图片保持可用。仅删除本程序为此编辑创建且已不被引用的图片。
- 图片经 Electron nativeImage 解码为 PNG；拒绝无效/过大图片。来源仅允许 HTTP/HTTPS；不执行文件或脚本。
- 安装成功但启用失败时关闭导入资料窗口并提示重试启用，保留单份已安装模组，不能因重复点击生成副本。
- 不增加依赖，不升版本，不构建发布产物，不提交已有混合工作。Windows x64 便携目标不变。

## 验收
核心测试覆盖普通/多个皮肤共存、切换、取消标记、方案、重启与更新保持；图片增删、空数组、写入失败与回滚；自动检查三种结果。界面冒烟覆盖两个常驻分区、红点无闪烁、图片编辑/切换/取消、导入选填资料和右键入口。运行 pnpm check、ui-assets 及受影响 smoke；Windows 实机单独标明未验证。
