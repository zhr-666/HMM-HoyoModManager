# ShaderFixes 分离安装与历史

用户要求：含 ShaderFixes 的模组正常安装，安装库副本不含该目录；下载解压后自动将文件放入加载器根目录的 ShaderFixes；“我的模组 → 替换 Hash”增加 ShaderFixes 历史记录。用户已选择同名保留、跳过并记录。

沿用既有 Library.install 入口，下载、本地导入与更新共用处理。大小写不敏感识别任意深度目录，保留其中的相对子路径。只接受 ShaderFixes 以外有 ini 的模组包；纯 ShaderFixes 包继续提示按作者说明处理。源文件不修改，脚本不执行。

目标由当前游戏 modsPath 的父目录确定；复用既有大小写目录，逐段阻止符号链接和非法 Windows 文件名，不写入安装库或源目录；沿用工作区对 data/components 内置加载器的已验证路径例外。未设置加载器时明确失败。已有同名文件、文件夹或链接均跳过，不覆盖。

每次记录来源模组名、包名、时间、目标目录、文件相对路径及写入/跳过/失败状态，独立保存于当前游戏数据目录。写入前保存意图；中断留下“待核对”记录，重试不会覆盖已存在文件。已成功写入的共享文件不会因后续模组安装失败而删除，记录始终可查。历史保存失败时停止继续写入。

界面只提供历史查看，展示完整目标路径供用户在文件管理器中手动删除；不提供自动删除或随模组移除清理，避免误删共享文件。切换标签或游戏后，旧异步响应不得覆盖当前面板。

v1.0.1 发布后用户反馈找不到 ShaderFixes 按钮。原实现只把历史放在「替换 Hash」弹窗的第四个标签中，顶层没有独立入口。修正为「我的模组」工具条直接显示「ShaderFixes 历史」按钮，点击后打开同一历史面板；原标签保留。

验证覆盖嵌套/大小写、同名保留、源不变、重启与移除后历史、写入/记录失败与重试、链接拒绝、下载与取消。运行 pnpm check、界面资源测试和相关 Electron 冒烟。Windows 实机仍需单独验收。不升版本、不打包发布。
