# 游戏数据归档与主页动画

基于 feat/game-program-tabs（b812dec），保留程序标签页功能。

所有游戏统一放在 `data/games/<game-id>/`；各自拥有 `state.json`、`library/`（含 Hash 备份）、`downloads/`、下载队列、`previews/`、`backgrounds/`、分类缓存及临时导入目录。原神没有特殊根目录。游戏 ID 来自统一注册表。全局设置与当前选择保存到 `data/workspaces.json`；会话、程序更新和应用通知/诊断保持应用级存储。外部启用库仍由用户选择，不搬动。

不做旧数据兼容或自动迁移，不删除旧目录；新版只读取新布局。安装、启用语义不变，不执行模组程序。

预览 URI 显式绑定游戏，切换游戏或后台加载图片时不能读错目录。文件操作失败时不覆盖已提交状态；未知游戏与路径穿越须拒绝。

主页视频按本地文件的 HTTP Range 语义提供数据，保持 no-store、正确长度与媒体类型；循环应持续播放，日常刷新状态不得重置播放进度。检验实际崩铁与绝区零视频至少多个完整循环，记录暂停、错误与帧间隔；无法由本机验证的 Windows 显示/解码行为留给实机验收。

复现：旧协议对 Range: bytes=0-99 返回 200/完整文件（崩铁 16004616 字节、绝区零 14701711 字节），两者 seek/loop 后触发 PIPELINE_ERROR_DECODE 并 paused=true。
