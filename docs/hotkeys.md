# 自定义热键扫描

入口：“我的模组 → 查看热键”。扫描安装目录及子目录中的 `.ini` 文件，按 `[Key…]` 节识别 `key`、`back`、`type`、`condition`、变量赋值和命令列表引用；重复的 key/back 均保留。配置名称和按键保持作者原文，不推断服装等实际效果。

安装和更新自动扫描，旧版记录首次启动补扫；打开热键窗口再次扫描。结果存入模组元数据，不改写配置文件、不重新部署模组、不发送游戏按键。DISABLED 路径中的条目单独标记；是否生效仍取决于加载器和运行条件。

支持 UTF-8、带 BOM 的 UTF-16 和 GB18030 解码回退。跳过符号链接；单个配置最多 4 MiB，总读取最多 32 MiB，最多展示 5000 组。读取失败或截断会显示说明，不将扫描失败当作安装失败。

语法依据：[3Dmigoto 官方配置示例](https://github.com/bo3b/3Dmigoto/blob/master/Dependencies/d3dx.ini)。本功能是静态配置查看器，不解析命令列表的完整运行行为，也不执行 include 指令读取安装目录之外的文件。

验证覆盖：重复绑定、反向键、条件和变量、注释、不同类型、递归目录、中文 UTF-16、DISABLED 标记、只读内容一致性、旧记录补扫、更新后替换扫描结果，以及真实 Electron IPC/只读弹窗。
