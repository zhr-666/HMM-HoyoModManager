# Windows 实机验收

## 1.1.2 后台检查更新、界面资源不缓存与启动器细节（Windows 实机待验收）

后台检查更新：

- 「我的模组」与「设置 → 维护与诊断」两处点「检查更新」：页面上方不再出现全局进度条；右下角先弹出「开始检查更新」，检查结束后再出现一条「检查完成」通知。
- 检查期间界面不锁死，可以继续翻页、下载或安装；连点「检查更新」不会重复发起。
- 检查结束后**不会**自动弹出结果窗口；「检查更新」按钮右上角出现红点（两个入口同时亮）。
- 有红点时点「检查更新」：直接打开更新结果窗口，红点熄灭；关窗后再点，才发起一次新的后台检查。
- 点历史里那条「检查完成」通知：打开更新结果窗口，红点熄灭，且不会重新发起网络检查。
- 重启软件后，历史里那条「检查完成」通知仍然点得开结果窗口（结果按模组库重建）。
- 全库没有任何模组时点「检查更新」：同样先弹「开始检查更新」，完成后通知「检查完成：全部模组已是最新」，不弹窗。
- 断开网络后点「检查更新」：通知里的失败数量正确；一个更新都没有且全部失败时为错误语气（红色），有更新又有个别失败时只按普通提示处理。
- 瞬时提示「开始检查更新」不进通知历史、不增加未读角标，重启后不会补弹一次。

界面资源不缓存（更新后界面必须是新版）：

- 用旧版本覆盖安装或自动更新到 1.1.2 后首次启动：界面样式、脚本和图标都是新版的，不残留上一版的界面。
- 更新后 `data/session` 下的 Chromium 缓存目录在启动时被清掉，且不影响 `data` 里的模组库、设置与通知历史。

启动器与消息中心的界面细节：

- 背景图从侧栏右边线起向右铺开，左右不出现空隙；改窗口大小后侧栏与背景左边界仍然对齐。
- 左栏游戏图标按加入顺序从栏顶往下排列；双击进入工作空间时图标飞向左栏最顶端；减少动态效果时动画简化。
- 「全部游戏」上方有一条更亮的横杠，位置在游戏列表下方。
- 通知中心按钮是线性消息图标（不再是铃铛 emoji），面板标题为「消息」；悬浮窗与面板比 1.1.1 更紧凑。
- 任务栏与窗口图标为 HMM / 草莓图标，多显示器与高 DPI 下不模糊；红点在 Windows 高 DPI 下位置正确、不遮挡按钮文字。

- 软件更新提醒点击后跳转到设置的软件更新卡片；模组更新提醒（启动自动检查）出现在历史里。

界面细节：

- 双击左栏游戏图标进入工作空间时图标飞向左栏顶端，减少动态效果时不播放动画；「全部游戏」上方有分隔线。
- 窗口滚动条细且半透明，滚动时显形、停下后淡回；设置项的问号提示悬浮与键盘聚焦都能看到说明。

## 0.9.5 角色互斥与单行按钮（Windows 实机待验收）

- 同一角色的两个工坊角色 Mod 依次启用，后者启用后前者停用；不同角色仍可同时启用。
- 同一音效、UI、非角色 Skins 和其他分类内多个 Mod 可以同时启用；本地导入保持各自独立。
- 多个非角色 Mod 与不同角色一起保存为搭配方案，停用全部后恢复方案，启用集合保持一致。

## 初次使用
- 完整解压，双击 HoYoMod.exe，中文窗口正常显示（标题栏与任务栏名称为 HMM、图标为草莓图标）；关闭重开后设置保留。
- 选择已有 GIMI 文件夹，自动连接 Mods；不要求 XXMI。
- 识别 GIMI Mods 路径；错误路径有说明，不覆盖原有 Mod。
- 网络不可用时本地库仍能使用，在线页面有重试说明。

## 批量替换 Hash
- 顶栏「替换 Hash」只在「我的模组」出现，点开是三标签（查找替换 / 替换记录 / 回溯记录）二级窗口。
- 预览时文件不变，列表显示所有命中模组、文件、次数。
- 执行后启用与未启用模组都替换，游戏加载目录中的启用副本同步；替换记录里能看到「什么值换成了什么值」。
- 重启后替换记录仍在，可在回溯记录里按批次回溯到替换前，确认原文件恢复。
- 修改文件后再回溯会停止，不覆盖后来的编辑；部署失败后原版本保留。

## 自定义热键
- 安装含多层目录与 Key 配置的模组，打开“查看热键”，确认组合键、反向切换键及来源行号。
- 查看前后 `.ini` 内容一致；旧模组可补扫，更新后热键同步变化。
- 游戏中满足配置条件时验证作者定义的按键；扫描仅展示配置，不执行或推断效果。

## Mod 工作流
- 按角色浏览、搜索、翻页，查看作者预览与文件选项。
- 选择一个兼容当前原神版本的普通外观 Mod，下载、安装、启用。
- 启用同角色另一个 Mod 后，GIMI/Mods/HoYoModManaged 中只有新条目；两个不同角色可以同时存在。
- 使用外部加载器启动游戏，确认所选外观生效。
- 管理器只保存部署文件；游戏中刷新由外部加载器处理。
- 保存组合、逐个停用、应用组合，验证游戏与本地部署一致。
- 「导入本地模组」悬浮出问号提示「选择文件后选择安装位置」；选压缩包后可以在大分类直接确认存放，磁盘上只出现一级目录。
- 列表上方的「安装库」打开 `data\library`，「启用库」打开 GIMI 的 Mods 目录。

## 更新、错误和便携
- 默认下载不启用；开启自动启用后下载即切换。
- 自动检查只提示；手动安装更新后保留启用状态和方案引用。
- 切换三种排序和 SFW/NSFW 勾选；NSFW 图片默认模糊，点击显示，设置开关生效。
- 下载记录保留网址与文件上传日期；安装失败后查看原因并重试缓存。
- 检查结束汇总全部更新、失败及未知项；最新 72 小时内的文件全部列出，不自动选择。
- 遇到多文件更新明确选择；断网/损坏包后旧版本仍可使用。
- ZIP、7Z、RAR 中的 DLL、EXE、Python 等文件原样安装，不由管理器执行；路径穿越、链接和异常解压大小仍拒绝。
- 关闭软件，移动完整便携目录后重开，库正常；内部组件与外部路径按界面提示重新设置。
