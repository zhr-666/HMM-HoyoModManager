# HoYoMod 1.1.1

日期：2026-09-27。状态：已发布，待 Windows 实机验收。标签 `v1.1.1` 指向 `70aff42`。

## 变更与兼容性

- 模组工坊的浏览工具改为全高侧栏；收起后显示当前搜索、排序、内容、分类与页码，翻页控件移至列表底部。
- 滚动条改为常显，移除两端箭头。
- 前置需求名称中包含 XXMI 或 3DMigoto 时，将其识别为基础运行环境，不再提示为缺失模组。
- 未引入数据迁移；更新流程仍只替换程序文件并保留 `data` 与加载器目录。
