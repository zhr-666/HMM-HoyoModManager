# HoYoMod v1.1.2beta3

日期：2026-09-30。状态：待 Windows 实机验收。预发布标签 `v1.1.2beta3`。

## 变更与兼容性

- 基于已发布的 v1.1.2beta2，纳入角色识别、圆形热键悬浮窗、拖动与展开动画的改进。
- 原神画面识别优先读取原始左右标题，失败时按需使用补救 OCR 和严格字形匹配；提供截图 ZIP/目录分析工具与回归样本。
- 不增加依赖或迁移用户数据；更新仍须保留 `data`、GIMI/ZZMI/SRMI/WWMI、Mods 和个人文件。预发布版不进入应用内正式版更新检查。

## 更新失败时恢复

退出 HoYoMod，将本版 ZIP 完整解压覆盖原程序目录，保留原 `data`、加载器目录、Mods 和个人文件；不要只替换 EXE。
