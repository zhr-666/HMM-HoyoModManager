# HMM v1.1.2

日期：2026-09-30。状态：已正式发布，待 Windows 人工验收。

## 范围与兼容性

合并 v1.1.2beta3 分支与当前悬浮窗可靠性分支，纳入当前未提交的首页全部停用、游戏独立悬浮窗开关和精简语言资源配置。包含工坊与设置修正、首页方案快捷切换、目标游戏 EXE 设置、最新背景选择、双区域 OCR、字形回退、识别恢复、同角色皮肤热键和长提示显示。

重叠的悬浮窗交互采用 2026-09-30 的圆形 HMM 图标、原生拖动、粉色详情窗和齿轮设置设计；扫描正常间隔 2 秒，空画面间隔 3 秒。保留 beta3 双区域识别和异步结果失效保护。首页方案快捷按钮与全部停用按钮并存。

不新增运行依赖，不迁移用户数据；模组仅安装、不执行。更新需保留 data、加载器 Mods 和个人文件。旧 HoYoMod 仓库的同名历史记录移至 [旧版记录](legacy/HoYoMod-1.1.2.md)，旧 ZIP 仅保留在本机 dist/legacy-HoYoMod-v1.1.2，不上传。
