# HoYoMod 0.9.5

日期：2026-09-16。源码标识：Git 标签 `v0.9.5`（与本记录一并提交）。用户明确要求打包发布到 GitHub，并指定版本为 0.9.5。

## 变更

- 仅同一角色的角色 Mod 互斥，不同角色及其他类型可同时启用多个；搭配方案和前置检查使用相同规则。
- 保存角色分类，支持离线启用；旧数据按需补齐分类，无法确认时明确提示。
- 操作按钮文字单行显示，按钮组可整体折行，长分类名称单行省略。
- 更新助手记录启动日志与提前退出原因，等待就绪上限延长至 60 秒；完整但尚未开始替换的更新可重试。
- 加入项目开发规则、统一检查入口和 GitHub 自动检查配置。

## 更新与恢复

旧版如果更新助手启动失败，请退出 HoYoMod，将完整 ZIP 解压覆盖到原程序目录，保留原 data、GIMI、Mods 及个人文件，不删除旧目录、不只替换 EXE。

已经开始替换但未完成的更新，应先关闭 HoYoMod 并使用原更新目录对应的 HoYoMod-Recover.cmd 恢复；保留 `.hoyo-updates` 中的日志和备份。新版本对启动失败的诊断改进不能自动修复正在运行的旧版更新器。
