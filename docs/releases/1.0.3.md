# HoYoMod 1.0.3

日期：2026-09-23。状态：已发布，待 Windows 实机验收。

源码提交：见 `v1.0.3` 标签；悬浮窗与 OCR 功能未进入本版。

变更与兼容性：三游戏角色分类名显示官方简体中文；安装库的旧分类记录只读显示，不迁移数据。ShaderFixes 文件分离安装并记录历史；首页默认背景与 Logo 更新；启动时按需加载当前游戏状态；通知中心顺序与可滚动区域调整；一级程序嵌入窗口的 Shell 样式修复。旧 `data`、GIMI/ZZMI/SRMI 和手动模组应保留，仍需 Windows 升级实测。

执行环境：macOS，Node.js 24.21.0，pnpm 11.19.0，Electron 44.3.0；构建 Windows x64 便携 ZIP。

检查命令与结果：

- `pnpm check`：语法检查 116 个 JavaScript 文件；404 项测试中 402 通过、0 失败、2 项 Windows 专用测试按平台跳过。
- `node --test tests/ui-assets.test.cjs`：4 项通过。
- `node scripts/smoke-multi-game.cjs`、`node scripts/smoke-library-folders.cjs`、`node scripts/smoke-notifications.cjs`、`node scripts/smoke-program-tabs.cjs`：通过。
- `node scripts/smoke-program-windows.cjs`：按平台跳过，需要 Windows x64 管理员桌面。
- `node scripts/smoke-home.cjs` 与 `node scripts/smoke-management.cjs`：本地缺少未锁定的 Playwright 模块，未运行。
- `pnpm pack:win`：成功；`ELECTRON_RUN_AS_NODE=1 pnpm exec electron scripts/verify-windows-package.cjs`：包内源码和 Windows x64 程序校验通过；`ELECTRON_RUN_AS_NODE=1 pnpm exec electron scripts/smoke-update-package.cjs`：真实 ZIP 更新准备、保护数据与模组校验通过。
- `git diff --check`：通过。随包包含使用说明、MIT 许可证和第三方版权说明。

Windows 实机结果：待验收。需从上一正式版本升级后核对界面缓存、三游戏背景与角色名、ShaderFixes、窗口任务栏/Alt+Tab/任务视图行为，以及更新失败恢复和图标。
