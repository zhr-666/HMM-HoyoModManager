# HoYoMod v1.1.2beta2

日期：2026-09-28。状态：待 Windows 实机验收。预发布标签 `v1.1.2beta2`。

## 变更与兼容性

- 包含 v1.1.2beta 的界面调整；修复游戏热键悬浮窗点击后失焦、任务栏弹出、自动消失及无法再次打开的问题，并将扫描间隔缩短为 750 毫秒。
- 原神处于前台且尚未识别到角色时显示半透明 HMM Logo；切到后台或退出游戏时隐藏。
- 各游戏设置独立的目标游戏 EXE；目前原神 OCR 悬浮窗使用该设置，其他游戏的 OCR 尚未接入。
- 原神启动器有多个背景视频时按 URL 日期选择较新的视频及其对应海报。
- 未引入数据迁移；更新仍保留 `data`、加载器目录和用户模组。此版本为 prerelease，不进入应用内正式版更新检查。

## 更新失败时恢复

退出 HoYoMod，将本版 ZIP 完整解压覆盖原程序目录，保留原 `data`、GIMI/ZZMI/SRMI/WWMI、Mods 与个人文件；不要只替换 EXE。
