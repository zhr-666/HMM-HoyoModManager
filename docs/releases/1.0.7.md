# HoYoMod 1.0.7

日期：2026-09-24。状态：本地构建与验证完成，待 GitHub Windows CI 和正式发布。

源码：`feat/release-1.0.7`，功能提交 `0c7e6fa`，版本号提交 `7aa56fa`；本版整合此前的鸣潮背景、首次使用提示、工坊评论与窗口操作改动。

变更与兼容性：工坊详情可在程序内放大当前图片；右下角提示卡手动关闭时删除对应通知历史，自动消失仍保留；GameBanana 模组排序增加到官方配置的 12 种。安装库、启用库及用户 `data` 不迁移。

Release 正文（用户提供）：优化部分交互逻辑和页面UI，修复鸣潮背景问题。

执行环境：macOS，Node.js 24.21.0，pnpm 11.19.0，Electron 44.3.0；本地构建 Windows x64 便携 ZIP。

已执行检查：

- `pnpm exec electron scripts/smoke-workshop-comments.cjs`：评论读取、回复重试、排序切换、当前大图放大及返回、文件直达下载和窗口操作通过。
- `node scripts/smoke-notifications.cjs`：手动删除、自动收起保留、磁盘同步、重启恢复通过。
- `node scripts/smoke-notification-layer-and-pager.cjs`：通知顶层和工坊翻页回顶通过。
