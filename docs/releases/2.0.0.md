# HoYoMod 2.0.0

日期：2026-09-22。状态：**已构建并通过 macOS 自动验证，Windows 实机待验收**。

## 主要变化

- 新增原神、绝区零、崩坏：星穹铁道三个独立游戏工作区，分别连接 GIMI、ZZMI、SRMI；模组、方案、下载、分类和游戏设置相互隔离，公共规则统一生效。
- 通知中心常驻区分“进行中的任务”和“消息”，分类可折叠；悬浮入口只用红点提示。启动自动检查软件更新时，无更新保持安静，有更新或失败时弹窗并保留消息。
- 同一角色可同时启用一个普通模组和任意多个皮肤模组；右键可切换皮肤模组标记。
- 模组资料支持修改作者、来源和多张预览图，可从文件或剪贴板添加；本地导入最后一步可补充资料。
- GameBanana 预览图和分类图标缓存到本地；本地导入不再做不可靠的前置依赖推断。
- 启动器首页使用半透明侧栏。绝区零与星穹铁道显示游戏官网 Logo；背景从窗口左侧铺满。官方静态或动态背景完整下载后原子替换，离线可用；每个游戏可独立开启启动自动更新背景。
- 程序不再下载、配置或启动 XXMI。用户直接选择已存在且含 `d3dx.ini` 的加载器目录，也可选择一个外部 EXE 由按钮打开。

## 数据与兼容性

原神旧数据保留原位置；绝区零和星穹铁道使用 `data/games/<游戏ID>`，安装副本使用 `data/library/<游戏ID>`。背景缓存放在 `data/backgrounds/<游戏ID>`。完整结构见 `docs/data-layout.md`。更新程序继续保护整个 `data`、各游戏启用库与用户指定的外部程序。
