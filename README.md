# HoYoMod · 原神模组管理

Windows x64 便携桌面程序。按分类浏览 GameBanana，下载和安装 Mod，管理本地库及搭配方案，通过 XXMI/GIMI 启动原神。

## 0.6.1 分类导航与安装修正

- 工坊和本机模组按 GameBanana 完整层级浏览；本机分类使用对应图标，路径前提供返回上一级按钮。
- 下载入队后顶部提示 3 秒；程序及脚本随模组原样安装，管理器不执行。

## 0.6.0 分类、记录与更新规则

- 模组工坊按 GameBanana 原神的分类层级浏览：首层显示大分类按钮，点击后只显示直属子分类，可沿路径返回任意上级。每一层均分页展示该分类及其后代分类的模组；分类搜索只筛选当前层级。
- 下载次数由真实统计接口补齐，读取失败显示“暂不可用”，不再显示虚假的零。
- 详情文件选择改为等宽卡片，文件名、大小和上传日期更清晰。
- 下载加入队列后，窗口顶部显示“已加入下载列表”，3 秒后自动消失，不打断浏览。
- 失败任务重试时复用记录；可删除单条或清空全部历史，保留等待、下载、安装中的任务。仅删除记录，不删除已安装模组或下载缓存。
- 新下载自动保存来源总分类和具体角色/子分类；“我的模组”按 GameBanana 完整层级显示有本机模组的分类，使用对应分类图标，路径前可返回上一级，各层展示所属全部本机模组；磁盘保存于 `data/library/总分类/角色或子分类/模组版本目录`。目录名附加稳定标识，避免重名。旧版目录继续兼容，更新安装时采用新结构。
- 同一 Mod 页面最新文件上传时间向前 72 小时（含边界）内的文件视作同一版本；已安装文件在此范围内不提示更新，旧版本则列出这段时间内的全部文件供手动选择。
- Windows 顶部标题栏延续窗口背景材质，保留系统最小化、最大化和关闭按钮。

## 0.5.0 下载与界面改进

- 独立下载列表：后台排队、进度、错误、重试和取消等待任务；下载期间仍可使用其他页面。
- 下载 Mod 前必须选择有效的 GIMI Mods 目录；首次安装官方 XXMI 组件不受此限制。
- 我的模组图片直接显示，启用/停用使用开关；模组工坊切换页面后保留筛选、结果和滚动位置。
- 设置置于侧栏底部；支持浅色、深色、跟随系统，以及 Windows 11 22H2 及以上的亚克力/云母背景。其他系统使用普通背景。
- 下载长度不匹配、连接中断会自动重试；服务器支持范围请求并提供一致的文件标识时可断点续传。RAR 改为磁盘流式解压，移除原 256 MB 包和 512 MB 单文件限制。

## 使用

1. 完整解压 `HoYoMod-0.6.1-Windows-x64.zip` 到可写文件夹，运行 `HoYoMod.exe`。不要只取出 EXE，其他文件也必须保留。
2. 在 **设置 → 下载官方组件** 安装 XXMI 便携组件。已有 XXMI 可以直接选择其 `Resources/Bin/XXMI Launcher.exe`。
3. 点击 **打开 XXMI 配置**，在 XXMI 窗口选择原神、安装 GIMI，并配置原神游戏路径。这一步需要 Windows 和已安装的原神。
4. 回到设置，自动查找或手动选择 GIMI 的 `Mods` 文件夹。其上一级应包含 `d3dx.ini`。使用已有 GIMI 时，请先将旧 Mod 移出 `Mods` 或改为 `DISABLED` 前缀，避免与本管理器部署的内容叠加。
5. 进入模组工坊选择角色，打开 Mod 详情，选择作者提供的具体压缩包下载；也可在“我的模组”导入 ZIP、7Z、RAR。
6. 启用喜欢的 Mod，再点击 **启动原神**。同角色新 Mod 会替换旧 Mod；不同角色可同时启用。运行中切换后软件会尝试发送 F10；若未生效，请返回游戏手动按 F10。

## 批量替换 Hash 与回滚

“我的模组 → 批量替换 Hash”：输入旧值和新值，点击查找预览，确认模组、文件和匹配数量后执行。扫描所有已安装模组（包括未启用模组）的 `.ini` 及子目录，完整值匹配，不区分大小写。包含注释内的完整匹配；不替换更长标识符中的一部分。接受 8–64 位十六进制值及可选 `0x` 前缀。

保留原文件编码、BOM 与换行。每批保存受影响模组的完整目录备份，保留在 `data/library`，需要额外磁盘空间，请勿手动清理。已启用模组同步到 GIMI 加载目录。

“替换记录 → 回滚此批次”恢复替换前文件；同一模组的连续替换从最新批次开始回滚。如果模组随后更新、移除、或文件被手动修改，程序会停止回滚，避免覆盖后续内容。回滚保留当前启用状态和搭配方案。文件替换成功不保证新 hash 与当前游戏版本兼容。

## 自定义热键

“我的模组 → 查看热键”展示安装目录及子目录 `.ini` 中的 `[Key…]` 配置，包括按键、反向切换、类型、生效条件、变量/命令及来源行号。支持 `cycle`、`toggle`、`hold` 等配置，组合键保留作者写法。

安装、更新时自动扫描；旧版记录首次打开新版时补扫，每次查看也会重新读取。仅展示，不改写 `.ini`。DISABLED 路径中的配置会标记，扫描结果不代表该配置正在游戏中生效。包含条件或命令列表的实际效果仍以作者说明为准；没有标准 Key 配置的自定义系统可能无法识别。

## 功能约定

- 预览来自 GameBanana 作者图片，角色名称保留来源站名称。
- **下载后自动启用** 默认关闭；开启后安装成功即切换角色使用的 Mod。
- 工坊支持按下载量、上传时间、更新时间排序；SFW、NSFW 默认均勾选。NSFW 依据来源站分级保守识别，不分析图片；仅勾选 NSFW 时逐页筛选，可能出现空页，可继续翻页。
- 模组工坊和详情中的 NSFW 图片默认模糊，点击可显示；设置中可关闭模糊。我的模组图片始终直接显示。
- 下载记录保存来源网址、所选文件与上传日期。下载使用系统代理设置，显示速度并重试短暂中断；实际速度仍受来源站及网络影响。
- 安装失败会保留下载文件，在左侧“下载列表”查看原因、打开位置或重试。自动启用失败不会丢失已安装的模组。
- “我的模组 → 检查更新”比较文件上传时间，检查完汇总所有更新和失败项。最新上传时间向前 72 小时内的文件全部列出，由用户选择安装。
- **自动检查更新** 默认关闭；开启后启动时与每 6 小时检查，只标记和提示，不自动安装。旧版自动更新设置迁移为自动检查。
- 旧模组缺少文件时间时，尝试按文件编号或唯一同名文件恢复；无法确定时显示“无法判断”，不会将页面编辑误认为文件更新。
- 搭配方案保存所有角色的启用组合，应用空方案会禁用全部 Mod。
- Mod 文件与状态位于程序同级 `data`。搬动整个便携目录后本地库仍可读取；外部 XXMI/GIMI 路径可能需要重新选择。
- 所有分类均可浏览；自动安装仍面向 GIMI/3DMigoto 格式，其他加载方式的模组请遵循作者说明。压缩包需要包含 `.ini`，不执行 Mod 作者的脚本或程序。DLL、EXE、Python 等程序及脚本随模组原样安装，管理器不会运行它们；链接或不安全路径仍会拒绝安装。下载上限 2 GB，解压上限 4 GB；RAR 解压超过 180 秒会中止，暂不支持加密或分卷 RAR。
- 本管理器保证库中同角色条目的互斥。作者在**单个压缩包内打包多套互斥版本**时，需要先按作者说明整理为一套再导入，不能仅靠文件夹自动判断所有游戏冲突。
- “已发送刷新/启动请求”不代表游戏内加载成功；需要在游戏窗口确认。若修改过 GIMI 的默认 F10 刷新键，请恢复默认键或手动使用自己的刷新键。

## 代理与下载故障

默认使用系统代理。需要手动指定时，在设置中选择手动代理，填入代理软件实际提供的 HTTP 或 SOCKS5 地址，例如 `http://127.0.0.1:7890`（端口以你的代理软件为准），保存后测试连接。诊断显示 DIRECT 时，流量仍可能被 TUN 接管。

`net::ERR_CONTENT_LENGTH_MISMATCH` 表示传输长度与响应声明不一致，可能涉及服务器、链路中断或代理，单凭报错不能确定原因。程序会保留可续传数据并重试，只有校验通过的完整文件才进入安装。自动重试失败后，可在下载列表重试；实际速度取决于来源站和代理链路。

升级时先退出旧版，完整解压新版，再将旧版整个 `data` 文件夹复制到新版程序旁，保留本地库、设置与替换备份。

## 开发

需要 Node.js 22+、pnpm，首次安装需要网络。

```sh
pnpm install
pnpm test
pnpm start
pnpm pack:win
```

如果包管理器跳过 Electron 安装脚本，运行 `node node_modules/electron/install.js`。

桌面集成冒烟测试：安装 `playwright` 后运行 `node scripts/smoke-desktop.cjs`，或通过 `PLAYWRIGHT_MODULE` 指定现有 Playwright 包路径。测试使用系统临时目录，不触碰用户 Mod。

## 验证范围

当前开发机为 macOS。自动测试覆盖真实文件部署、同角色互斥、更新回滚、搭配方案、目录搬迁、压缩包校验；桌面测试验证 Electron 界面与主进程连接。GameBanana 接口以真实公开响应验证。

Windows 原神启动、GIMI 初始化、F10 刷新和具体 Mod 的游戏版本兼容性仍需要 Windows 实机验收。详见 [验收清单](docs/acceptance.md)。
